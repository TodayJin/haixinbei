## 2. 电源架构（按网表实际器件）

| 轨 | 实现 | 电流 | 谁在用 |
|---|---|---|---|
| **12V** | CN1 → U6 开关 → **F1 5A 自恢复保险丝** → **Q3 P-MOS 反接保护** → TVS D2 → **R2 5mΩ/1206 分流** → 12V_PROT_OUT | 电机电流 | **U3 / U4 的 VM**、U7 / U8 两路 buck 输入 |
| **VSERVO 7.4V**（网名 VCCSTEER） | **U7 = SP1N28STER** + L1，FB 由 **50k 可调电阻 R30** 设定 | 5A | U11 舵机座 2/5/8/11 脚 |
| **5V** | **U8 = SP1N28STER** + L2 → **D5 = SS54 防倒灌** → VCC5V | 3A | 循迹座、I2C/UART 座、**编码器霍尔**、蜂鸣器、U9 输入 |
| **3.3V** | **U9 = RT9013-33GB** LDO（5V→3.3V） | 500mA | MCU、JY61P、INA226、I2C 上拉 |

要点：

- **保险丝在开关之后、反接保护之前**：F1 是 2920 自恢复保险丝（SMD2920-500-24）。
- **反接保护 Q3** 用 P-MOS 接在高边（PJQ4465AP，PowerPAK 1212-8），栅极由 R8 + D1 组成；D2 是 SMF15CA 双向 TVS。
- **分流 R2 在保护之后**，所以 INA226 量到的是「保护后送到负载的全部电流（含两路 buck）」，**不含保护器件自身损耗**。U5 高侧接法：`U5.10 = IN+`（源侧）、`U5.9 = IN−`、`U5.8 = VBUS` 都接负载侧。
- **5V 的 SS54 是刻意串的防倒灌**（外部 5V 倒灌不回头灌进 buck），**反馈取在 D5 之后**，所以 5V 仍然稳在 5V，不用管那 0.3–0.5V 压降。
- **7.4V 出厂要调**：U7 的 FB 挂 R30（50k 可调）+ R16/R17。**上电后用万用表量 U11 的 2 脚，把 R30 调到 7.4V** 再插舵机 —— 这是全板唯一需要人工校准的点。
- **4 个电源指示灯**（各串限流电阻到 GND）：12V → LED1+R38 10k；7.4V → LED5+R18 10k；5V → LED6+R24 4.7k；3.3V → LED7+R26 2.7k。
- ⚠️ **只用调试口的 3.3V 上电时，5V 指示灯会微亮** —— VCC3V3 与 VCC5V 之间只有 **U9（RT9013）** 一个元件，它的 PMOS 体二极管会从输出倒灌到输入，把 5V 轨顶到 ~2.7V。**正常现象，不是故障**；此时 12V / 7.4V 灯不亮。详见 [固件接口规格.md](../固件接口规格.md) 坑清单第 11 条。

## 3. 驱动：2× AT8236

| 项 | 值 |
|---|---|
| 位号 | **U4 = 电机 A**，**U3 = 电机 B**（ESOP-8，各一颗单路 H 桥） |
| 控制 | 每颗 2 根输入，**PWM 直接打输入**，不需要额外的使能脚 |
| 限流 | **ISEN（脚 7）直接接 GND** → 检流电压恒 0，**不启用逐周期限流**；**VREF（脚 4）接 3.3V**（推荐范围 0.5–4V 内，因 ISEN 接地实际不起作用） |
| 散热 | ESOP-8 底部 **EPAD 接 GND + 大面积铺铜 + 过孔阵列**（必做） |
| 故障 | AT8236（**非 N 版**）**没有 FAULT / OTW 输出**，MCU 读不到故障状态 —— 因此 **PB0/PB1/PB2 省下来了** |

- 电机 A：`PC6 = MOTA_IN1`、`PC7 = MOTA_IN2`（TIM8_CH1/CH2）；电机 B：`PC8 = MOTB_IN1`、`PC9 = MOTB_IN2`（TIM8_CH3/CH4）。
- 每根输入串 **100Ω（R6/R9/R10/R11）** + 对地 **100k 下拉（R12/R13/R14/R19，在 MCU 侧）**：抑制振铃，而且**上电/复位期间默认低电平 → 电机不转**（安全）。
  - 下拉值不敏感：AT8236 输入端**内部还有一个下拉**，外部这个 100k 是第二重保险 → 几十 k 到几百 k 都可用。
  - **换成 73k 更好**（拉低更硬、抗干扰更强，多耗 12µA 可忽略）；**200k 能用但抗干扰变差**（省 16µA 没意义）；**别低于 ~10k**（拖累 MCU 驱动）。
- 真值表：一高一低 = 一个方向；反过来 = 另一个方向；**都高 = 刹车**；**都低 = 滑行**。
- PWM 建议 **20kHz**；「哪根是前进」取决于电机线序，**上台架标定一次**，固件里封装成 `motor_set(id, signed_speed)`。
- 电机座 **U33 / U34（PH2.0-6P）**：1 = 电机−、2 = GND、3/4 = 编码器 A/B、5 = +5V、6 = 电机+。**线序以你手上电机实物为准**，别照表盲焊，丝印要对得上。
- ⚠️ **务必买 AT8236（立创 C2827823），不要换成 AT8236N**：两版**第 4 脚定义相反** —— AT8236 的 4 脚是 VREF（本板接 3.3V），AT8236N 的 4 脚是 **nFAULT 开漏输出**。本板 4 脚是硬接到 3.3V 的，换成 N 版后只要过流/过温把 nFAULT 拉低，就等于把 3.3V 直接对地短路。
- **没有逐周期限流**（ISEN 直接接地）→ 堵转 2.5–3.5A 超过 3A 连续额定，靠内部 OCP(6–10A)/TSD 兜底，**别长时间堵转**；要限流得在 ISEN 上串检流电阻（要割线改板）。

## 4. 编码器 / 舵机 / 人机

- **编码器**：电机 A → **TIM3（PB4/PB5）**，电机 B → **TIM4（PB6/PB7）**；5V 霍尔，**10k 上拉到 5V + 串 100Ω + 100nF 对地**（PB4–PB7 都是 5V 容忍 FT，不需要分压，所以 v0.8 说的「三焊盘跳线」**已取消**）。
- **计数**：11 PPR × 4 倍频 × 45 = **1980 计数 / 输出轴圈**；150rpm ≈ 4950 计数/s。
- **舵机**：U11（2.54 3×4P）4 路，`PA8–PA11 = TIM1_CH1–4`，50Hz，信号串 100Ω，供电 7.4V。
- **五向键**：U10 = GT-TC006D-H060-L1（SMD-8P），公共端 GND、低有效、**用 MCU 内部上拉**，软件消抖 10–20ms。占 `PC13/PC14/PC15/PC2/PC3`。
- **蜂鸣器**：`PD2` → Q1（S8050，基极 R7 + 下拉 R15）→ BUZ1，并 **D3 续流**，蜂鸣器接 5V。**PD2 = 1 鸣响**。
- **复位**：SW1 + R1 10k↑3V3 + C15 100nF。
- **BOOT0**：就在 **PB8**（PB8-BOOT0）上，只接了 **R3 10k↓GND**，**没有跳线**（板上无外挂 Flash，固定从内部 Flash 启动）。

## 6. 关键电路要点

- **INA226 采样**：R2 两端必须**四线 Kelvin**（取样线从焊盘内侧单独引出，不要共用大电流走线）；VS 就近 100nF。ALERT **不接**，只用 I2C 轮询。
- **I2C 总线**：板上 R4/R5 = **4.7k → 3.3V**；循迹模块自带 10k，并联后 ≈ **3.2k**。⚠️ **I2C 座（U14/H3）的第 1 脚给的是 5V**，调试时量一下总线空闲电压：≈3.3V 正常，**≈3.8V 说明模块那 10k 上拉接的是 5V**，要拆掉或改到 3.3V。
- **晶振**：25MHz 紧贴 PF0/PF1，包地、下方禁走线；固件 `HSE_VALUE` 必须改成 25000000，PLL = **/5 ×68 /2 = 170MHz**。
- **JY61P**：装在板中心附近，远离驱动/电感/电机线；UART 走线短，模块固定牢、加软垫减震。
- **测试点**：12V / 7.4V / 5V / 3.3V / GND、SWD、串口、I2C 都留焊盘。
- **原理图有两处网名与实际相反**（不改也能用，但别被名字骗）：`I2C2_SCL/SDA` 其实是 **I2C1**；`LPUART1_TX/RX` 其实是 **PC0=RX、PC1=TX**。代码按实际功能写。

## 7. PCB 布局布线建议

1. **层次**：强烈建议 **4 层**（信号 / GND / 电源 / 信号）；做 2 层就上 **2oz 铜**。
2. **分区**：12V + 驱动 + 电机接口靠板边 → 电源区 → MCU + 晶振（中部）→ 传感器 / 人机接口（另一侧）。
3. **AT8236**：两颗分开摆、各自贴近对应电机座；EPAD 大铺铜 + 过孔阵列；VM 就近 100µF + 100nF。
4. **电机电流**：U33/U34 到 OUT 的走线短、粗、直（持续 2–3A / 峰值 3.6A）；**功率地与信号地分开、单点汇接**。
5. **开关节点**：U7/U8 的 SW 节点（L1/L2）铺铜面积最小化，远离晶振、INA226 取样线、JY61P。
6. **丝印**：标清 **12V / 7.4V / 5V / 3.3V** 和每个座的名字，避免插错。
7. 四角 **M3 安装孔**（SCREW1–4）。

## 8. 已否决的替代（别重开，除非先讨论）

| 被否的 | 为什么 |
|---|---|
| DRV8412 / DRV8432 | 太贵；AT8236 够用且省下 3 个控制脚 |
| TB6612FNG | 1.2A 余量太小 |
| RZ7899-MS | 标 6A 实为 ~3A，SOP-8 无散热焊盘 |
| STM32G431RBT6 | RAM 只有 32KB |
| STM32G474RET6 / LQFP100 的 VET6 | Flash/引脚用不上，更贵更大 |
| 板载 ICM-42688-P（SPI2） | 用户要沿用 JY61P |
| 板载 ESP32-C3 / nRF24L01 | 已有外接无线下载器 |
| I2C2 用 PC4/PC5 | **PC5 根本没有 I2C 功能**，组不成 I2C2 |
| 把 I2C1 放在 PB8/PB9 | **PB8 = BOOT0**，上拉会把 BOOT0 拉高导致不启动 |
| RGB / WS2812 | 用户明确「暂时先不要」 |
| INA226 ALERT 做中断 | 轮询够用；PB12 空着备用 |
| BOOT0 跳线 | 板上无外挂 Flash，启动模式固定 |

另：**I2C 上拉 R4/R5 保持 4.7k**（不改成 2.2k），理由与并联计算见 `固件接口规格.md` 3.4 节。
