## 1. 一句话

4.5m × 4.5m 的宝丽布场地上铺引导黑线，沿线布置 **11 个不同难度的障碍**；
机器人**自主**跑，**5 分钟内**尽可能多地挑战障碍；按**单次运行的最高障碍得分**计分。

## 4. 评分与流程（第 47–48 页）

### 得分
- 综合得分 **C = I（障碍完成分，满分 185）+ II（计时分，满分 5）**，满分 **190**。
- **I 取"单次运行完成障碍的最高得分"，不累积**：重跑时之前的分数仍有效，但只认单次最高。
- 计时分 II = 比赛终止时的**剩余时间**换算，精确到秒（剩 3 分 25 秒 → 3.25 分）；5 分钟耗尽得 0 分。
- 名次：先比 C；C 相同比**跑完全程耗时**；再相同比**作品重量**（轻者靠前）。

### 得分判定（关键）
- **1~10 号障碍**：必须**沿黑线延伸方向从前端进入、从末端离开**才算过。
  从侧边进出、执行机构未充分进入、重复通过同一障碍 → **不得分**。
- **11 号高台只要求登上并充分进入**，**不需要通过** → 45 分。
- 不得分情形：未从前端进入 / 未从末端离开 / 行动机构未充分进入障碍范围 / 重复通过 / 裁判认定的其他情况。

### 流程与限制
- 每个作品现场运行总时间 **5 分钟**，从**首次启动**开始计时，中途不暂停（极端情况除外）。
- 上场前**称重**并记录；签到后统一抽签定顺序。
- **参赛作品应自主控制，不允许任何形式的远程控制干预。**
- 挑战失败可由内场裁判把车交回选手，**重新运行次数不限**；每次运行间隙可在场边调整，
  但**不得改变结构设计方案**，也不得带离裁判指定范围。
- 终止条件：5 分钟耗尽 / 选手申请结束 / 裁判判定必须终止。

## 5. 对开发的直接影响（重点）

### 5.1 机械与电气的硬约束

| 约束 | 来源 | 说明 |
|---|---|---|
| **整车高度（含舵机臂/支架）必须 < 20 cm** | 5、6 号隧道**净高 20cm** | 车顶任何部件超过 20cm 就钻不过去，两个 10 分障碍直接丢 |
| **车宽/轮距要能过 25 cm** | 10 号窄桥桥面宽 25cm | 宽于 25cm 会掉桥 |
| 要爬升 **16.2 cm** 的窄桥坡 | 10 号窄桥 | 坡度 = 16.2/95 ≈ **17°**（按底长 95 算） |
| 要爬 **10.8 cm** 的小型阶梯（每级 3.4cm） | 3 号 | 单级 3.4cm，轮径与离地间隙要够 |
| 要登 **约 20.5 cm** 的高台（45 分，只需登上） | 11 号 | 全场最高分值，值得专门设计攀爬机构 |
| 通过 1 号栅格（格 6cm、高 3cm） | 1 号 | 轮子易卡格 |
| 柔软草地 4cm 草绒 | 8 号 | **打滑**：里程/航向全靠编码器+陀螺，打滑会让航位推算失真 |
| 防滑带 5cm 三角木条 | 7 号 | 高频颠簸，陀螺与循迹都会抖 |

### 5.3 策略（规则直接推出来的）

1. **稳 > 快**：计时分最多 5 分，而一个内围障碍就 20 分、高台 45 分。任何为省时间而降低成功率的改动都是负收益。
2. **单次最高分不累积** ⇒ 不必一次跑完全部；**按分值排序逐个啃**（高台 45 → 内围 4×20 → 外围 6×10）。
3. **失败可无限重跑** ⇒ 每个障碍都该有"卡住 → 后退重试"的恢复逻辑，而不是卡住就报废整轮。
4. **必须前端进、末端出** ⇒ 障碍入口的姿态比速度重要；建议进障碍前用陀螺锁航向对准黑线延伸方向。
5. **不允许遥控** ⇒ 无线链路**只能在运行间隙做调参/导出**，绝不能用于运行中干预。

### 5.4 对上位机的合规提醒

上位机（`tools/console/`，"控制与日志"页）能启动任务、改参数、软复位。
**比赛运行中禁止用无线做任何控制**（规则明令）。
场上用法应限定为：**运行间隙**读参数 / 下发调好的参数 / 看波形与日志复盘。
建议现场纪律：上场前断开上位机连接，或只打开"控制与日志"页。
