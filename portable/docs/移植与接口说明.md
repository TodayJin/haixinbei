## 1. 板级契约 `board.h`

### 1.1 引脚宏与时钟

`board.h:31-84` 用 `#define` 固定 7 组功能（I2C1、USART3、LPUART1、五向键、蜂鸣器、
电机 4 路、编码器 4 路）。宏名是**功能名**，换板只改 `GPIOx / GPIO_PIN_n`。

```c
typedef struct {                      /* 全部按寄存器回读填写，供 RTT 打印/判据 */
  uint8_t  hse_ok, pll_used, hse_ready, hsi_ready, pll_locked;
  uint32_t sysclk_hz, hclk_hz, pclk1_hz, pclk2_hz, flash_latency;
} clock_report_t;
void board_clock_init(clock_report_t *rep);
```

| 项 | 内容 |
|---|---|
| 调用者 | `main.c` 在 `HAL_Init()` 之后、**任何外设初始化之前** |
| 必须做到 | 开 PWR 时钟 → `HAL_PWREx_DisableUCPDDeadBattery()`（坑 3）→ 配 HSE+PLL → `HAL_RCC_ClockConfig(..., FLASH_LATENCY_x)` |
| 必须返回 | `rep` 填真实回读值；HSE 起振失败要有 HSI 兜底（参考实现退回 16MHz 并照常返回） |
| 参考实现 | `参考板级适配层/board.c:16-100`（HSE 25MHz、PLL /5 ×68 /2 = 170MHz、LAT=4） |

### 1.2 I2C1 与总线自愈

```c

I2C_HandleTypeDef *board_i2c(void);
HAL_StatusTypeDef board_i2c_enable_dma(void);           /* DMA1_Ch1 + I2C1_EV/ER 中断 */
DMA_HandleTypeDef *board_i2c_dma_tx(void);
HAL_StatusTypeDef board_i2c_write(uint8_t a7, const uint8_t *b, uint16_t n);
HAL_StatusTypeDef i2c_read_reg(uint8_t a7, uint8_t reg, uint8_t *b, uint16_t n);
HAL_StatusTypeDef i2c_write_reg(uint8_t a7, uint8_t reg, const uint8_t *b, uint16_t n);
HAL_StatusTypeDef i2c_probe(uint8_t a7);
void     board_i2c_report(uint8_t ok);      /* 每次读写报结果（喂总线看门狗） */
uint8_t  board_i2c_watchdog(uint8_t bus_idle);
uint32_t board_i2c_recover_count(void);
uint32_t board_i2c_scl_hz(void);

```

| 函数 | 谁调用 | 必须返回/做到 |
|---|---|---|
| `board_i2c_init_hz(hz)` | `main_app.c:82`（400kHz） | `HAL_OK`；时序按 PCLK 现算，不抄魔数；必须早于 `OLED_Init()` |
| `board_i2c_enable_dma()` | `main_app.c:86` | `HAL_OK`；函数内先 `__HAL_RCC_DMAMUX1_CLK_ENABLE()`（漏了 DMA 永不传输，`board.c:332`） |
| `i2c_read_reg` / `i2c_write_reg` | `kk_oled`、`trace_cal`、INA226 | 超时 50/50/200ms；失败后要 `board_i2c_report(0)` |
| `board_i2c_report(ok)` | 每次读写之后 | 无返回，喂 `bus_health` 的连续失败计数 |
| `board_i2c_watchdog(bus_idle)` | 主循环每拍 | 1 = 这次真恢复了总线（阻塞 ~12ms）；`bus_idle=0` 必须跳过 |
| `board_i2c_bus_recover()` | 看门狗 / OLED 重试 / 显示自愈 | 无返回；只能在总线空闲时调，恢复后按 `s_i2c_scl_hz` 重配（`board.h:109-121`） |
| `board_dl_*()` | `host_link_init/poll` | `board_dl_baud()` 必须等于实际波特率；发队列满丢帧计数 |
| `board_jy61_get_byte()` | 主循环 | 1 = 取到一字节，0 = 无数据（**非阻塞**） |
| `keys_raw()` | `app_ui` 每拍 | 位定义固定（上/下/左/右/中），低有效转"1=按下" |

### 1.3 三条串口

```c

HAL_StatusTypeDef board_uart_jy61_init(void);

void board_jy61_start_rx(void);
int  board_jy61_get_byte(uint8_t *b);        /* 无数据返回 0 */

HAL_StatusTypeDef board_uart4_init(void);
void board_uart4_write(const uint8_t *d, uint16_t n);
int  board_uart4_read_byte(uint8_t *b, uint32_t timeout_ms);

/* LPUART1：上位机链路 921600，收=DMA1_Ch2 循环，发=DMA1_Ch3 队列 */
HAL_StatusTypeDef board_dl_init(void);
uint32_t board_dl_baud(void);                /* 波特率唯一真值，别手抄 */
void board_dl_start_rx(void);
int  board_dl_get_byte(uint8_t *b);
HAL_StatusTypeDef board_dl_send(const uint8_t *d, uint16_t n);

```

- **USART3 不能靠主循环轮询**：11 字节 1ms 内到齐，100ms 轮询只收到第 1 字节。
- `board_dl_baud()` 必须返回实际生效值；上位机默认 `--baud` 必须与它一致（现 921600）。
- 联调顺序：先 `host_link_send_text()` 证明"发"，再看 `HOST: rx=` 证明"收"。

### 1.5 按键 / 蜂鸣器 / 不属于 board.h 的板级责任

```c
void    board_gpio_keys_init(void);   /* 5 路输入 + 内部上拉，低有效 */
uint8_t keys_raw(void);               /* bit0上 bit1下 bit2左 bit3右 bit4中，1=按下 */
void    board_buzzer_init(void);
void    board_buzzer_mark_on(void);
void    board_buzzer_safety(void);    /* **5ms 中断**调用，响超 150ms 强制掐掉 */
void    board_buzzer_off(void);
```

| 责任 | 现在在哪 | 换板注意 |
|---|---|---|
| SysTick / `HAL_GetTick()` | `HAL_Init()` | 换主频后重新确认 tick 精度 |
| Flash 擦写 | **`nvram.c`、`task_store.c` 直接调 `HAL_FLASH`** | 擦除粒度/页大小变了要改这两个文件 |
| 中断向量 | `Core/Src/stm32g4xx_it.c`（**不在包里**） | 补 `LPUART1`、`DMA1_Ch2/3`、`I2C1_EV/ER`、`TIM6_DAC`、`TIM7_DAC` |
| 链接脚本 | `参考板级适配层/STM32G474RBTx_FLASH.ld` | Flash 只给 116K（页 58 起是任务区/NVRAM） |

`board_buzzer_safety()` 必须放在 `HAL_TIM_PeriodElapsedCallback()` **两个分支之外**，
这样主循环卡死也不会一直响（`main_app.c:328`）。

## 2. BSP 契约

`bsp_board.h` 暴露 `htim1/htim8/htim6/htim7/htim3/htim4_enc`，另有别名 `htim2`(=TIM6)、
`htim4`(=TIM7) 供旧上层 extern。

```c
void bsp_motor_init(void);     /* TIM8 四路起，初值 CCR=0 → 电机不转 */
void bsp_servo_init(void);     /* TIM1 **只启动 CH1/CH2** */
void bsp_encoder_init(void);   /* TIM3/TIM4 编码器模式 + PB4..PB7 复用 */
void bsp_periodic_start(void); /* TIM6/TIM7 5ms，NVIC 优先级 6 */
void bsp_trace_init(void);
GPIO_PinState bsp_trace_bit(uint8_t idx);   /* 0..7 */
```

| 定时器 | 配置 | 为什么 |
|---|---|---|
| TIM8 | `PSC=0`、`ARR=MOTOR_PWM_MAX-1=7199`（23.6kHz） | 保留旧板 0..7200 刻度，PID 参数不用重标定 |
| TIM1 | `PSC=169`（1MHz）、`ARR=19999`（20ms）、50Hz | `CCR` 直接等于脉宽 µs（500..2500） |
| TIM3/4 | `PSC=0`、`Period=0xFFFF`、`TIM_ENCODERMODE_TI12`、`IC1Filter=10` | 4 倍频；5ms 内几十个计数，不溢出 |
| TIM6/7 | `PSC=169`、`Period=period_ms*1000-1` | 5ms 一拍；`GYRO_DT`/`SPEED_PERIOD_MS` 都按它写死 |

```c
/* motor.h：对外语义"正 = 该轮朝前进方向"，刻度 ±7200 */
void Load(int moto1, int moto2);            /* 右路取负在 motor.c 内部完成 */

/* servo.h：x 只认 1/2；脉宽夹 500..2500µs */
void Servo_SetPulse(int x, int pulse_us, int dev_us);
void Servo_SetAngleDev(int x, float angle, int dev_us);   /* 500 + 2000*angle/180 */
void Servo_MoveTo(int x, float angle, uint32_t ms);       /* 非阻塞，Servo_Task 推进 */
void Servo_Task(void);                                    /* TIM7 5ms */

/* encoder.h：读并清零，带符号，正 = 前进 */
void Encoder_Init(void);
void Encoder_Reset(void);
void Encoder_ReadDelta(int *left, int *right);
```

- `Servo_SetPulse()` 只认 1/2 号（`servo.c:38-42`），所以 CH3/CH4 **故意不启动**：
  一旦启动就被钉死在初始 500µs 且没人能改。
- `Encoder_ReadDelta()` **只许 `SpeedControl_Task()` 每 5ms 调一次**（读完清零，别人调会偷计数）；
  电机若不再镜像安装，`motor.c` 与 `encoder.c` 的符号要**成对**改（只改一边 = 速度环正反馈）。

```c

```

```c
/* speed_control.h：目标/输出都是 PWM 刻度；反馈是编码器 */
void SpeedControl_Enable(uint8_t on);
void SpeedControl_SetTarget(int left, int right);
void SpeedControl_SetTargetRamp(int l, int r, float ramp_pwm_per_s);
void SpeedControl_SetFeedforward(float slope, float fric);

int  SpeedControl_Counts(int wheel);          /* 本拍原始增量（计数/5ms） */

int  SpeedControl_Output(int wheel); int SpeedControl_Target(int wheel);
```

换算（`speed_control.c:299-306`）：`mm/s = 计数/5ms × 200 / counts_per_rev × π × wheel_dia`。
`counts_per_rev`（`0x0305`，默认 1456）、`wheel_dia`（`0x0306`，65mm）在参数表里。
前馈 `out = slope×target ± fric + PI`（`0.662 / 2327`，参数 `0x0605/0x0606`）。

```c
/* gyro_control.h：输入是 jy61p.h 的 Yaw/Pitch/Roll/Gyro_Z，GYRO_DT=0.005f */

uint8_t GyroControl_TurnDone(void);

```

| 文件 | 对外 | 数据口径 |
|---|---|---|
| `tracing.h` | `read_tracing_data()`、`tracing_data[8]`、`trace_invert` | 0/1，优先标定后的模拟量 |
| `trace_cal.h` | `trace_cal_init/poll/channel/level/frame`、`trace_cal_disp_*` | 模拟量 0..255；`channel()` 返回 -1 = 该路不可用 |
| `PID_tracing.h` | `motor_tracing_pid_speed(base)`、`motor_tracing_cascade(base)` | 重心 1..8，正中 4.5 |

串级模式下循迹环输出的是**目标转率 °/s**（不是差速）；差速直出由参数 `0x0213` 与模式决定。

## 4. 通信层接口

```c
void host_link_init(void);               /* 建 LPUART1 + 参数表 + 发启动横幅 */
void host_link_poll(uint32_t loop_us);   /* 主循环每拍：收帧 + 按频率发遥测 */
void host_link_tick_1hz(void);           /* 每秒 RTT 打一行链路统计 */
void host_link_send_text(const char *s); /* 任意时刻塞一行文本给上位机 */
const host_link_stats_t *host_link_stats(void);   /* rx/tx/crc/resync/param_sets/telem_hz */
```

帧格式（全部小端）：`A5 5A | type(1) | seq(1) | len(1) | payload(len) | crc16(2)`，
CRC16/CCITT-FALSE（poly `0x1021`、init `0xFFFF`，覆盖 type/seq/len/payload；
标准校验值 `"123456789"` → `0x29B1`）。CRC 错只前移 1 字节重同步。

| 帧 | 号 | 帧 | 号 |
|---|---|---|---|
| `T_TELEM` / `T_TELEM2` / `T_TELEM3` | 0x01 / 0x03 / 0x04 | `T_PARAM_GET/SET/REPORT/SAVE` | 0x10/11/12/13 |
| `T_CAL_GET/REPORT/REPORT_B` | 0x14/15/1F | `T_ACTIONS_GET/ACTIONS/ACTION_SET/ACTION_SAVE` | 0x16/17/18/19 |
| `T_SERVO_SET/PLAY` | 0x1A/1B | `T_DRIVE/DRIVE_REPORT` | 0x1C/1D |
| `T_CMD/T_ACK/T_SESSION` | 0x20/21/22 | `T_LOOP_STATUS/RAW_TRACE` | 0x24/26 |
| `T_PARAM_SAVE_ACK` | 0x33 | `T_HELLO/HELLO_REQ/TEXT` | 0x40/41/50 |
| `T_TASK_LIST…COMMIT` | 0x60..63 | `T_TASK_GET…STATUS` | 0x64..69 |

参数表 API（控制代码唯一取参入口）：`SPECS[]` 与上位机 `bridge/params.py` 必须同序同值，
否则 `param_crc` 不匹配。

```c
float    host_param_get(uint16_t id, float fallback);
uint8_t  host_param_u8(uint16_t id, uint8_t fallback);
uint32_t host_param_u32(uint16_t id, uint32_t fallback);
void     host_param_set_local(uint16_t id, float v);
uint16_t host_param_count(void);        /* = 58 */
uint16_t host_param_id_at(uint16_t i);
int      host_param_bounds(uint16_t id, float *def, float *lo, float *hi);
uint16_t host_param_table_crc(void);    /* = HELLO 里报的 param_crc */
```

遥测：`T_TELEM` 定长 **32B**（`pwm_r` 线上是原始极性，右路镜像 ⇒ 双轮前进为负，上位机解码取反）；
`T_TELEM2` **64B**（前 32B 逐字节相同，后接灰度 8 路/重心/PID/角度环/模式/任务号/舵机角）；
`T_TELEM3` **96B**（+偏航角速度、速度环目标/输出、tx_drop、rx_overrun、param_crc）。
默认 **200Hz**（`host_link.c:1566`），`CMD_SET_TELEM_HZ` 可改 1..200。

驾驶与安全 `host_ext.h`：

```c
int  HostExt_DriveSet(uint8_t mode, int a, int b);  /* 0 成功 / -1 模式非法 / -2 任务在跑 */
void HostExt_DriveStop(void);
void HostExt_DriveKeepAlive(uint32_t now_ms);       /* 每收到一个合法帧调一次 */
void HostExt_Task(uint32_t now_ms);                 /* 每拍：看门狗 + 低压保护 */
```

| 模式 | 含义 |
|---|---|
| 0 OFF / 1 WHEELS | 停车 / a,b = 左右轮 PWM 刻度 |
| 2 BASE | a = 基准速度、b = 相对转角 |
| 3 TRACE / 4 TRACE2 | 三级串级循迹 / 差速直出循迹 |
| 5 HOLD | a = 基准速度、b = **绝对目标航向 ×10** |

三条安全规则（`host_ext.h:62-77`）：500ms 无合法帧自动停车；母线连续 500ms < 3000mV
认定电池被拔（停驾驶 + 停任务）；任务解释器在跑时拒绝远程驾驶。

## 5. 存储层接口

```c
/* nvram.h：设置 + 标定 */
void    nvram_init(void);      /* 上电一次，在 app_ui_init() 之后 */
void    nvram_poll(void);      /* 主循环：200ms 检查、改动静 1.5s 才写 */
void    nvram_service(void);   /* 主循环：**排在 app_ui_tick() 之后**真擦写 */
void    nvram_touch(void);     /* 跳过防抖，立刻请求保存 */
uint8_t nvram_state(void);     /* IDLE/BUSY/DONE，界面据此锁键 */
uint8_t nvram_loaded(void);
```

记录：`magic(4)="HXB1" | version(2)=13 | length(2) | CRC32(4) | payload(N) | pad(4)`，
落在 `0x0801F800`（页 63 / 块 31）。整条记录必须 8 字节对齐（编译期断言
`nvram_record_size_must_be_8x`），因为按双字写。

迁移铁律：**只往末尾加字段**（旧记录按 length 取前缀）；**占用 pad 区**必须
`NVRAM_VERSION += 1` 且在 `nvram_init()` 里对老版本显式赋默认值。反例：v13 的
`task_speed` 从 `pad7` 抠出，不迁移则老存档读成 0 → `TaskRun_Start()` 以 base=0 起步 → 对转。

```c
/* task_store.h：任务镜像持久化（页 58 目录 + 页 59..61 程序区，8 槽） */
void     TaskStore_Init(void);                 /* 上电扫描，**只扫不启动** */
uint8_t  TaskStore_SlotCount(void);
uint8_t  TaskStore_Present(uint8_t slot);
uint16_t TaskStore_Len/Crc(uint8_t slot);
const uint8_t *TaskStore_Image(uint8_t slot);  /* XIP 指向 Flash */
uint8_t  TaskStore_Page/Block(uint8_t slot);
int      TaskStore_Load(uint8_t slot);
void     TaskStore_StageReset(void);
int      TaskStore_Stage(uint16_t off, const uint8_t *d, uint16_t n);
int      TaskStore_Commit(uint8_t slot, uint16_t len, uint16_t crc,
                          uint8_t flags, const char *name, uint8_t name_len);
int      TaskStore_Erase(uint8_t slot);
```

返回码：`0` 成功 / `-1` 参数 / `-2` **车在动拒绝擦写** / `-3` CRC / `-4` 结构 / `-5` Flash / `-6` 空槽。
目录页：头 8B（`magic=0x5453`、`ver=2`、`count`、`seq`、rsv）；每条 40B（`id`,`off`,`len`,
`crc16`,`flags`,`name_len`,`name[30]`）。`flags.bit0`（开机自启）**已废弃**。

| `OLED_Init()` | 返回 `OLED_OK` 才成功；序列含 `8D 14` 内部电荷泵、`AD 30` 内部 IREF |
| `OLED_Update()` / `_UpdateIT()` / `_UpdateDMA()` | 三种刷新运行时可选（诊断固件靠这点一次烧录跑四组合） |

## 7. 节拍、超时与上电顺序

| 周期/超时 | 值 | 出处 |
|---|---|---|
| 控制拍（三层串级） | **5ms** | `bsp_board.c:18`（`GYRO_DT`、`SPEED_PERIOD_MS` 都按它） |
| 舵机缓动 | 5ms | `bsp_board.c:19` → `Servo_Task()` |
| 屏帧节流 / 应用重绘闸门 | 20ms / 20ms | `kk_ui_config.h`、`main_app.c:263` |
| 遥测 | 200Hz（1..200 可调） | `host_link.c:1566` |
| 主循环空转 | `HAL_Delay(2)`，实测 ~235Hz | `main_app.c:314` |
| 链路看门狗 / 陀螺失联 | 500ms / 500ms | `host_ext.h:62`、`motion.c:24` |
| I2C 总线恢复 | 连续失败 5 次、间隔 ≥1s | `bus_health.h:24-25` |
| 显示自愈 | 每 300ms 重试，第 3 次连带复位总线 | `disp_heal.h:24-26` |
| NVRAM 保存 | 200ms 检查 / 1.5s 防抖 / 失败 5s 退避 | `nvram.c:47-50` |
| 蜂鸣器保险丝 | 150ms | `board.c` 的 `BEEP_MAX_MS` |
| OLED 初始化重试 | 150ms 等待 + 10 次 ×（恢复 + 50ms） | `main_app.c:146-165` |

上电顺序（照 `main_app.c:59-205`，顺序错会**静默**失败）：

```
HAL_Init → DWT → RTT 横幅 → board_clock_init
→ keys/buzzer → I2C 400k → I2C DMA → host_link_init
→ bus_health_init → bsp_trace_init → trace_cal_init
→ Motor_Init → Servo_Init（PWM 全 0，电机不转）
→ bsp_encoder_init → Encoder_Init → [MOTOR_BENCH] → Motion_Init
→ bsp_periodic_start（TIM6/TIM7 起，5ms 控制环开始跑）
→ USART3(JY61P) → OLED_Init（带重试）→ app_ui_setup_display → test_pattern
→ app_ui_init → nvram_init → TaskStore_Init → 主循环
```

主循环（`main_app.c:207-315`）：`trace_cal_poll` → `read_tracing_data` → 喂 JY61 字节 → `app_ui_tick`
→ `nvram_service` → `host_link_poll` → `host_link_tick_1hz` → 每 20ms `KK_UI_Invalidate`
→ `nvram_poll` → `TaskRun_Tick` → `HAL_Delay(2)`。
